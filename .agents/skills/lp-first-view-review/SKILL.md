# LPファーストビュー審査

LP のファーストビュー（FV）案を、公開前に自分で審査するための手順。FV は 3 秒で判断される前提で見る。

## 手順

1. **3秒テスト**: FV を 3 秒表示して閉じ、「誰向けの・何の・どんな得があるサービスか」を口頭で言えるか確認する。言えなければコピーが弱い。
2. **コントラスト検査**: 見出しと背景のコントラスト比 4.5:1 以上。CTA ボタンは周囲より一段強い色にする。
3. **視線導線**: ロゴ → 見出し → 補助コピー → CTA の Z 型に沿っているか。人物写真の視線は CTA 側へ向ける。
4. **CTA 文言**: 「送信」「登録」は禁止。行動の結果が見える動詞句にする（例: 「無料で見積もりをもらう」）。
5. **モバイル折返し**: 375px 幅で見出しが 3 行以内に収まるか。収まらなければ文言を削る。

## 過去案件での学び

- A 社（工務店）の案件では FV に施工事例写真を必ず 1 枚入れる指定だった（担当の田中さんの強い要望）。工務店系は実績写真が最重要。
- B 歯科の案件では院長写真の笑顔カットに差し替えた結果 CVR が 1.8 倍になった。人物写真は プロ撮影 > ストック素材。
- C 社はブランドガイドで #E60012 以外の赤を禁止している。納品前に必ずガイド PDF を確認する。
